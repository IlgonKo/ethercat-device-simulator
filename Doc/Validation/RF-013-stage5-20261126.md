## 사용자 수동 확인

사용자가 Motion Server 버스 연결·초기화 완료를 알린 뒤 실린더 수동 테스트 완료를 보고했다. 이를 Motion Server/IO Control Panel → EtherCAT DO → 실린더 FMU → DI 리드백 경로의 사용자 수동 합격으로 기록한다. 센서 전환 시간, 반복 횟수, 해당 세션 WKC 수치·운전 시간을 직접 계측한 기록은 없으므로 수치를 만들지 않는다.

해당 시점 Soft ESC 구성은 기존 가상 F-KR 2축·Copley 2축에 CPX io1/io2, cylinder0/1, analog0/1을 추가한 구성이다. CPX 각각은 슬롯1 DI8·슬롯2 DO8·슬롯3 AIO4/4다. 실린더 입출력은 두 station에 분산 연결되어 있다. 물리 앞단에는 기존 실제 CMMT/CPX가 연결된 시험 구성을 사용했다. 이번 완료 보고가 축 이동·모든 장애·모듈 변경까지 확인했다는 의미는 아니다.

최신 설정을 지원하는 io-model-keys-20261126 이미지로 기존 컨테이너를 재생성하고 healthy를 확인한 뒤 사용자가 버스 연결·초기화를 수행했다. image ID: `sha256:6679ad7d3c3e72e6e8466bee2e1976dc3d58ef616d6ad647f8b56c794a406e77`. 이전 rf013-stage4 이미지와 새 AXIS_NAMES/IO_MODELS 설정을 섞어 사용하면 안 된다.

## 아날로그 수동 시험 생략 결정

IO Control Panel에 AO 출력 UI가 없고, 실제 지연 FMU 자동 시험이 완료된 것을 바탕으로 사용자가 아날로그 수동 시험 생략을 결정했다.

- 수용한 근거: [4단계 보고서](RF-013-stage4-20261126.md) 및 `tests/integration/test_io_fmu.py`.
- 검증된 범위: Int16 음수/0/양수/양 끝값, 지연 0/8/16/20/37ms/10초, 순서 보존, 다중 인스턴스/분산 station 연결, 일시정지·재개·버퍼 초기화. runtime Docker에서도 실제 FMU 시험 10개 통과.
- 물리 CPX AO 값 수신·SDO 값과 WKC는 [1~3단계](RF-013-stage1-3-20261126.md)에서 별도 확인했다. 이 시험은 실제 지연 FMU를 통과한 AI 왕복과 다르다.
- **미검증:** Motion Server → 물리 EtherCAT AO → 실제 지연 FMU → 물리 AI → Motion Server 전체 경로.
- 이 수동/물리 아날로그 왕복은 완료 필수 항목에서 생략하되 최종 검증 한계로 기록한다. UI 추가나 같은 수동 시험 재요청으로 바꾸지 않는다.

## 기존 근거 대조

- 짧은 계산 지연/중첩/고정 dt: test_short_overrun_keeps_result_without_catchup, test_model_steps_never_overlap 통과 기록. timeout latch·늦은 결과 폐기는 test_timeout_latches_and_discards_late_output.
- AI/AO 값/범위·독립성: test_analog_boundaries_without_clamp, test_invalid_output_freezes_model, 실제 FMU test_four_real_fmus_cross_station_pipeline_and_pause 등. 아날로그 계약 자체를 미완료로 남기지 않는다.
- CPX 매핑/SDO/OP: test_remote_io.cc 및 물리 probe의 지원 OD 읽기, 매핑 쓰기 거부, F030/F050, 27F1/이력 미지원 Abort, OP/PDO/WKC 근거를 재사용한다.
- CPX 2 station에서 Host SIGKILL 이후 340회/3초 WKC 6/6 및 정상 오류 요약 OD 유지가 이미 검증됐다. 현재 Drive+IO/FMU 세션의 지연·전체 영향·재시작 복구를 모두 검증했다고 확대하지 않는다.

## 후속 검증 완료 기록



CPX 모듈 구성 변경·고정 PDO 재생성·Master 재검색·원복도 완료했다. 슬롯4 DO8 추가, 출력 10→11바이트, F030/F050·assignment·DO 수신값을 확인했고 원복했다. [상세 결과](RF-013-reconfiguration-20261126.md).


기존 4번 자동 검증 보완은 완료했다. 실제 FMU 연결 경계, 값 유지/내부 상태/오류 latch, CPX 읽기 전용/진단 분리/메일박스 관측의 세 묶음이 통과했다. station·모듈·채널 목록의 진단 중복 기록은 사용자 결정으로 요구하지 않는다.

혼합 운전·계측(기존 1번)도 완료: 사용자 준비 상태에서 단일 TCP 클라이언트가 가상 4축·실린더 2개를 각각 15회 왕복시켰다. 60.531초, WKC 조회 1,171회 모두 24/24. [계측 결과·한계·복원 확인](RF-013-mixed-operation-20261126.md).

Host 장애·재시작 복구(기존 2번)도 완료했다. SIGSTOP/SIGKILL·SDO/PDO/마지막 값 유지와 초기 조건/저장값 복구를 확인했다. 실축 0x8188은 재연결 후 Reset으로 해제했다. [상세 결과](RF-013-host-recovery-20261126.md).

RF-013의 합의 범위 완료 기준을 모두 충족하여 완료 처리했다. 아날로그 수동/물리 전체 왕복은 생략 결정과 미검증 한계를 유지한다.
