## 구현

- 공통 Fmi3Runner에 initial_values를 추가했다. enterInitializationMode 이후, exitInitializationMode 이전에 프리셋·인스턴스 설정·초기 명령을 쓴다. 실제 초기 상태/출력에 반영된다.
- scalar 자료형·범위·메타데이터 min/max를 검사한다. fixed parameter는 초기화 이후 쓰기를 거부하고, 기존 Copley의 tunable parameter 갱신은 유지한다. eventModeUsed=False로 FMU 내부 이벤트 처리를 사용한다. [FMI 3.0.2 Co-Simulation 규격](https://fmi-standard.org/docs/3.0.2/).
- remote_io/adapter/fmi.py에서 DO extend/retract를 실린더 FMU Boolean 명령으로, 끝단 센서를 DI로 연결한다. 두 입력 ON도 그대로 전달한다. 공압 물리·밸브 방향 유지 처리는 FMU가 수행한다.
- raw Int16 아날로그 순수 지연 FMU를 C99/FMI 3.0 Co-Simulation으로 제작했다. 정수 이력 버퍼이므로 연속 ODE 솔버가 필요 없으며 Python에서 대신 계산하지 않는다. 독립 인스턴스, 초기 출력 0, delay_seconds 0..10초, 8ms 계산 경계 계약을 구현한다.
- 실린더 프리셋 cylinder_100mm와 지연 프리셋 analog_delay_16ms를 실제 모델에 연결했다. DEVICE_SIMULATOR_FMU_DIR은 설정 파일 기준 경로 또는 컨테이너 /model_artifacts를 사용한다.
- Docker builder에서 지연 FMU를 컴파일하고, 실린더 웹 Export는 검증된 원본 아카이브를 그대로 포함한다. 오프라인 배포 입력에도 실린더 파일을 포함하도록 확장했다. 런타임에는 컴파일러를 설치하지 않는다.

실제 FMU 시험은 다음을 확인했다.

- 지연 0/8/16/20/37ms/10초, 음수·0·양수·Int16 양 끝값 및 입력 변화 순서. t=0 입력의 0/16/20ms 지연 첫 출력은 8/16/24ms.
- 10초 경계의 부동소수점 시간 누적 오차를 발견하여 매우 작은 시간 비교 허용오차로 수정하고 경계 회귀를 통과했다.
- 지연 인스턴스별 버퍼 독립, 일시정지 동안 모델 시간/버퍼 유지, 재개 연속성, FMI reset 및 재생성 후 출력/버퍼 초기화.
- 실린더 50/100mm 설정, 왕복·센서·명령 OFF 시 방향 유지, 초기 위치 25mm, 공급 압력 0, 두 명령 ON 그대로 전달.
- 실제 FMU 4개의 cross-station 입력/출력 pipeline, 새 유효 입력 스냅샷을 모두 확보한 뒤 재개, 출력 전용 station 이탈 시 모델 계산 지속.
- 실제 native FMI 함수를 독립 worker에서 호출, 입력 하나 누락 시 초기화만 수행하고 모델 시간이 진행하지 않음.

배포 이미지 시험은 network none/read-only filesystem에서 실행했다. /tmp 및 실행 가능한 /run/fmu만 임시 쓰기 공간으로 주고 실제 FMU를 로드·계산했다. 이번 단계는 EtherCAT 물리 케이블 시험을 다시 수행하지 않았다.
