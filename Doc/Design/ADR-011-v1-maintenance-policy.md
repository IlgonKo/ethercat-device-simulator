# ADR-011 — Soft ESC v1.0 릴리즈 및 DT Demo 전 유지보수 경계

- 결정 상태: **채택**
- 결정일: 2026-11-26
- 근거: 사용자 요청으로 현재 구현·검증 범위를 Soft ESC v1.0으로 릴리즈하고 DT Demo 완료 전 신규 RF 구현을 중단한다.

## 결정

1. v1.0.0을 Git 태그·릴리즈 문서·버전 고정 Docker 이미지로 식별한다. 운영 설정/state는 릴리즈 소스에 포함하지 않는다.
2. DT Demo 완료 전에는 버그와 이미 구현된 기능의 미비점 보완을 TD로 진행할 수 있다. 수정 영향에 맞는 회귀를 검증하고 필요 시 1.0.x 패치 릴리즈로 제공한다.
3. 추가 기능 구현 RF는 진행하지 않는다. 새로운 모델·모드·API·프로토콜 지원 등을 TD로 이름만 바꿔 진행하지 않는다.
4. RF-021은 DT Demo 이후로 보류한다. RF-019/020은 v1.0/DT Demo 범위 외 장기 후속이며 구현하지 않는다.
5. RF-012의 최종 Demo 설정·새 Edge 배포 인수 검증은 Demo 사양 장비 설정 때 함께 진행한다. 기존 기능 설정·검증이며 신규 기능 구현 착수를 뜻하지 않는다.
6. 외부 Orchestrator·Pairing·Alignment·ROS2/Omniverse는 계속 Soft ESC 범위 밖이다.
7. DT Demo 완료 후 사용자와 범위·우선순위를 다시 확인하고 신규 RF 구현을 재개한다. 완료 시점 추정만으로 자동 재개하지 않는다.

## 릴리즈 판정과 제한

RF-015/022 및 기존 완료 RF의 합의 범위를 릴리즈 기준으로 한다. 새 PC/OS 배포·전체 Demo 통합·RT 보증·전 표준 적합성 완료를 의미하지 않는다. 알려진 모델별 차이는 [v1.0 릴리즈 문서](../Releases/v1.0.0.md)에 유지한다. 버그 수정이 지원 계약 자체를 확대해야 한다면 사용자와 범위를 확인한다.
