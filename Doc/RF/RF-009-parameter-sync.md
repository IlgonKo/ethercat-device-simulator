# RF-009 — 실제·가상 장치 양방향 파라미터 동기화

- 등록일: 2026-09-15
- 상태: 계획 / 미착수
- 설계: [DT-004](../Design/DT-004-parameter-sync-persistence.md)
- 선행: RF-005 공개 API·장치별 SDO 확인. 가상장치 저장은 RF-010과 연계.

## 작업 범위

별도 동기화 관리자에서 실제→가상 및 가상→실제의 비교·항목 선택·대상 백업·적용·readback을 구현한다. 장치별 허용 목록, 단위·범위·의존 관계와 쓰기 조건을 정의한다. 실제 장비의 비휘발성 저장은 별도 결과로 관리한다. 모드 전환과 독립 실행하며 기존 Motion Server를 수정하지 않는다.

## 완료 기준

- [ ] 기존 공개 API의 대상별 읽기·쓰기 가능 여부와 미지원 항목 기록.
- [ ] 양방향 비교·선택 적용·백업·readback 및 가상 영구 저장 검증.
- [ ] 식별/읽기 전용/실행 상태/PDO 통신 설정의 오적용 방지.
- [ ] 비교 이후 변경, 타입·범위 오류, 부분 실패·복원 실패·저장 실패 결과 구분.
- [ ] 모드 전환·모델 초기화와 동시 적용 차단 및 자동 운전 재개 없음 확인.
- [ ] 실제 장비 RAM 적용과 비휘발성 저장·재시작 필요 여부 구분.

## 검증 기록

미구현·미시험. API 미지원 및 TD-001 Abort 문제를 성공으로 우회하지 않고 관련 제한으로 기록한다.

## RF-005에서 이관 (2026-09-22)

기존 파라미터 API 존재는 코드로 확인했다. 실제/가상 대상별 읽기·쓰기·저장 및 쓰기 상태 조건의 실동작은 이 항목에서 검증한다. [RF-005](RF-005-mixed-bus-feasibility.md)는 기본 혼합 타당성 범위로 완료했으며, 이 후속 항목의 상태는 변경하지 않는다.
