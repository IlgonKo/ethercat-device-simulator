# RF-009 — 실제·가상 장치 양방향 파라미터 동기화

- 현재 상태: **범위 외**
- 상태 상세: 2026-11-25 독립 Soft ESC 제품 정의에 따라 외부 연동 구상 참고 이력으로 분리. 외부 프로젝트의 구현 상태를 판정하지 않음.

- 등록일: 2026-09-15
- 설계: [ADR-004](../Design/ADR-004-parameter-sync-persistence.md)
- 선행: RF-005 공개 API·장치별 SDO 확인. 가상장치 저장은 RF-010과 연계.

## 2026-11-25 범위 구분

이 항목은 과거 연동 구상의 참고 이력이다. DT Demo 논의에 따라 해당 상위 정책은 Soft ESC 구현 범위에서 제외한다. 아래 체크리스트는 기존 기록이며 외부 프로젝트의 현재 상태나 이번 Soft ESC 완료 조건을 뜻하지 않는다.

Soft ESC 측 필요한 장치 지원만 [프로젝트 계획](../project-plan.md)의 RF-013/015 및 기존 SDO/PDO 기능으로 대조한다. 외부 모드 전환·라우팅·ROS2·양방향 복사 로직을 이 RF를 근거로 구현하지 않는다.

## 이전 요구사항 — 현행 Soft ESC 작업 목록 아님

## 작업 범위

별도 동기화 관리자에서 실제→가상 및 가상→실제의 비교·항목 선택·대상 백업·적용·readback을 구현한다. 장치별 허용 목록, 단위·범위·의존 관계와 쓰기 조건을 정의한다. 실제 장비의 비휘발성 저장은 별도 결과로 관리한다. 모드 전환과 독립 실행하며 기존 Motion Server를 수정하지 않는다.

## 완료 기준

- [ ] 기존 공개 API의 대상별 읽기·쓰기 가능 여부와 미지원 항목 기록.
- [ ] 양방향 비교·선택 적용·백업·readback 및 가상 영구 저장 검증.
- [ ] 식별/읽기 전용/실행 상태/PDO 통신 설정의 오적용 방지.
- [ ] 비교 이후 변경, 타입·범위 오류, 부분 실패·복원 실패·저장 실패 결과 구분.
- [ ] 모드 전환·모델 초기화와 동시 적용 차단 및 자동 운전 재개 없음 확인.
- [ ] 실제 장비 RAM 적용과 비휘발성 저장·재시작 필요 여부 구분.

## 검증 기록

미구현·미시험. API 미지원 및 TD-001 Abort 문제를 성공으로 우회하지 않고 관련 제한으로 기록한다.

## RF-005에서 이관 (2026-09-22)

기존 파라미터 API 존재는 코드로 확인했다. 실제/가상 대상별 읽기·쓰기·저장 및 쓰기 상태 조건의 실동작은 이 항목에서 검증한다. [RF-005](RF-005-mixed-bus-feasibility.md)는 기본 혼합 타당성 범위로 완료했으며, 이 후속 항목의 상태는 변경하지 않는다.


## 2026-10-28 RF-010에서 후속 범위 확정

실제→가상 및 가상→실제의 비교·적용·저장·재시작 복원 연동은 이 RF에서 검증한다. RF-010은 가상 저장소와 SDO 저장·복원 기반으로 완료하며, RF-009 미구현이 RF-010 완료를 막지 않는다. 가상 저장 성공을 실제 장치 비휘발성 저장 성공으로 간주하지 않는다. 관리 API는 RF-019, revision/변경 이력은 RF-020과 연계한다. 이번 분리로 양방향 동기화가 구현됐다는 의미는 아니다.
