# RF-019 — 가상장치 파라미터 관리 API

- 현재 상태: **예정**
- 상태 상세: 계획 / 미착수 — RF-010에서 명시적으로 분리

- 등록일: 2026-10-28
- 연계: RF-010, RF-009, RF-020; RF-018의 일반 진단·Recovery API와 구분

## 범위

별도 관리 경로에서 파라미터 조회·변경·명시적 저장 결과를 제공한다. EtherCAT SDO와 동일한 검증 및 저장 정책을 사용하고, 두 경로의 동시 갱신·소유권·실행 상태 조건을 정의한다. 전송 방식·주소·인증 및 API 계약은 구현 전에 합의한다. RF-010의 내부 Python 호출을 공개 API 구현으로 간주하지 않는다.

## 완료 기준

- [ ] SDO/관리 API에서 적용과 영구 저장 결과를 구분하고 동일 값·오류 계약 검증.
- [ ] 지원 목록·타입·단위·쓰기 조건, 동시 요청/오래된 값의 처리 계약 정의.
- [ ] 저장 실패·모델/Host 장애·명령 충돌 시 결과 및 비자동 운전 재개 확인.
- [ ] 사용 예·호환성·테스트 문서화.

Model/Slave Recovery·위치 수락·DT 제어까지 자동으로 범위를 확대하지 않는다.
