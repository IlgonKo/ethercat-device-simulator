# RF-015 — 가상축 위치 제한 및 회전 경로 동작 정리

- 등록일: 2026-09-22
- 상태: 계획 / 상세 정책 미결정
- 연계: RF-011 다중 축 구성, RF-010 파라미터 저장

## 범위

RF-011에서는 기존 모델 동작을 유지한다. 본 항목에서 PP/PV/CSP/Jog의 Position_limit 적용 정책과 회전축 modulo·연속 회전·최단 경로 지원 필요성을 별도 논의한다. 현재 차이를 실제 CMMT 사양으로 간주하지 않는다.

## 현재 확인

181° 목표 거부는 기본 0x607D 상한 +180°의 결과이며 고정 모델 한계가 아니다. 모델은 공통 수치와 OD 단위·스케일로 계산한다. 현재 PP/CSP 목표 입력 검사, PV 위치 한계 정지 부재, Jog 바깥 방향 목표 속도 0 처리, 공통 한계 상태 비트 표시가 존재한다. wrap/최단 경로 처리는 없다.

## 완료 기준

- [ ] 실제 대상 장치 문서와 요구사항을 근거로 모드별 제한 정책 합의.
- [ ] 회전축 좌표 표현·회전 방향·범위/오버플로 및 modulo 지원 범위 합의.
- [ ] 합의한 변경과 경계값·방향전환·모드전환 회귀 검증.
- [ ] 기존 직선축·회전축 및 저장 파라미터 호환성 확인.

RF 등록은 개선 구현이나 특정 회전 정책 채택을 뜻하지 않는다.
