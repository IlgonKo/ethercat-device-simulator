- 등록일: 2026-09-15
- 상태: 계획 / 미착수

## 작업 범위

- Omniverse 연결 방식과 장치→USD Prim, 단위·좌표 매핑 설정을 정의한다.
- 선택한 그룹의 축 실제 위치 및 지원 IO를 장면에 반영한다.
- 전환·오래된 값·연결 끊김 표시와 화면/통신 주기 분리를 구현한다.

## 완료 기준

- [ ] 실제/가상 모드 모두 같은 논리 장치 매핑으로 DT가 해당 리드백을 따름.
- [ ] 목표값 대신 피드백 사용, 전환 시 허구의 이동 보간과 이전 상태 혼입 없음.
- [ ] 지원 IO·시간 지연·상태 유효성 기준 및 검증 결과 기록.
