# RF-007 — 모델 상태 초기화 및 모드 전환

- 등록일: 2026-09-15
- 상태: 계획 / 미착수
- 설계: [관련 결정](../Design/DT-002-mode-switching.md)
- 선행 조건: RF-005 통과, RF-006 전환 제어 경계 확보.

## 작업 범위

- 기존 가상축·가상 IO를 내부 모델 실행 계약으로 연결하고 관리용 상태 초기화 인터페이스를 정의한다.
- 실제→가상 스냅샷 초기화, 가상→실제 현재 상태 수용 절차를 구현한다.
- 정지 조건·필수 상태·유효성·센서 일관성·실패 처리 및 전환 세션을 정의한다.

## 완료 기준

- [ ] 정지 전환 성공과 누락·오래된 상태·초기화 실패·통신 장애 시 명령 차단 검증.
- [ ] 가상→실제 전환에서 자동 위치 맞추기·IO 출력 적용·대기 명령 재생이 발생하지 않음.
- [ ] 지원 장치 상태와 복원 불가능한 상태·전환 제한을 명시. FMI 실제 연동은 후속.

## 검증 기록

아직 구현·시험하지 않았다. Motion Server 제품 코드 변경을 전제로 진행하지 않는다.

## RF-005에서 이관 (2026-09-22)

비선택 그룹 대기 상태와 시작·restart 시 양쪽 그룹 영향, 전환 중 명령 차단 정책을 검증한다. [RF-005](RF-005-mixed-bus-feasibility.md)는 기본 혼합 타당성 범위로 완료했으며, 이 후속 항목의 상태는 변경하지 않는다.
