# RF-006 — 명령·리드백 라우터

- 현재 상태: **범위 외**
- 상태 상세: 2026-11-25 독립 Soft ESC 제품 정의에 따라 외부 연동 구상 참고 이력으로 분리. 외부 프로젝트의 구현 상태를 판정하지 않음.

- 등록일: 2026-09-15
- 설계: [관련 결정](../Design/ADR-001-system-architecture.md)
- 선행 조건: RF-005 검증 통과.

## 2026-11-25 범위 구분

이 항목은 과거 연동 구상의 참고 이력이다. DT Demo 논의에 따라 해당 상위 정책은 Soft ESC 구현 범위에서 제외한다. 아래 체크리스트는 기존 기록이며 외부 프로젝트의 현재 상태나 이번 Soft ESC 완료 조건을 뜻하지 않는다.

Soft ESC 측 필요한 장치 지원만 [프로젝트 계획](../project-plan.md)의 RF-013/015 및 기존 SDO/PDO 기능으로 대조한다. 외부 모드 전환·라우팅·ROS2·양방향 복사 로직을 이 RF를 근거로 구현하지 않는다.

## 이전 요구사항 — 현행 Soft ESC 작업 목록 아님

## 작업 범위

- 기존 서버 프로토콜에 맞춰 Client 연결과 단일 서버 연결을 중계한다.
- 논리 축·IO ID를 실제/가상 그룹으로 매핑하고 응답·상태를 역매핑한다.
- 선택 모드, 제어권, 전환 세션 및 명령 차단을 구현한다.

## 완료 기준

- [ ] 명령은 선택 그룹에만 전달되고 Client·DT 리드백도 동일 그룹에서 제공됨.
- [ ] 이전 세션 응답·상태 혼입 방지, 오류·연결 끊김 표시 검증.
- [ ] 전체 대상 명령·라우터 우회·동시 Client 정책과 기존 Panel 호환성 기록.

## 검증 기록

아직 구현·시험하지 않았다. Motion Server 제품 코드 변경을 전제로 진행하지 않는다.

## 추가 확인 — ID 공간

- [ ] [ADR-005](../Design/ADR-005-device-configuration.md) 기준 전체 Slave 번호, 서버 Axis 번호·IO ID, Simulator 로컬 순서·영구 ID를 구분한 명령/응답 매핑 검증.
- [ ] 논리 축 0 → 실제 Axis 0 / 가상 Axis 5 예시와 서버 IO io0 ↔ io1 매핑 검증. 매핑은 라우터 자체 설정이 소유한다.

## RF-005에서 이관 (2026-09-22)

시작 시 전체 축 Enable, 단일 축 restart의 전체 축 Disable 영향 및 서버 단위 제어권을 반영해 일반 선택 명령과 시스템 운용 명령을 구분한다. [RF-005](RF-005-mixed-bus-feasibility.md)는 기본 혼합 타당성 범위로 완료했으며, 이 후속 항목의 상태는 변경하지 않는다.
