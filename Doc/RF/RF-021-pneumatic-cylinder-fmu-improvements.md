## 목적과 확정 범위

현재 SoftESCDoubleActingCylinder는 공급원·배관·파일럿 밸브·5/2 메모리 밸브·복동 실린더를 포함한다. 정격 유량은 유로 특성을 정하는 **동작 모델 설정**이며 실제 유량은 계산 결과다. 정격 유량 설정을 FMU 외부에 노출해 같은 FMU의 인스턴스마다 다른 유로 특성을 적용할 수 있도록 한다. OD/SDO 장치 파라미터를 추가하는 요구가 아니다.

- 현재 공급원 `supply.qn`과 실린더 포트 `cylinder.qn_port` 등의 정격 유량은 원본 소스 내부에 있으며, 선택 FMU의 외부 parameter로 노출되지 않는다.
- Modelica 래퍼에 외부 설정을 추가하고 해당 부품에 연결한 뒤 FMU를 다시 Export한다. 공급원·밸브·실린더 포트의 서로 다른 정격 유량을 하나의 값으로 임의 통합하지 않는다.
- 노출할 부품별 항목·이름·단위·허용 범위·정격 조건을 구현 전에 명세한다. 원본의 표준 정격 유량(l/min)과 실제 질량 유량(kg/s)을 구분한다.
- 기본값은 기존 모델과 동일하게 유지하고, 변경 설정을 인스턴스별로 독립 적용한다.
- Soft ESC에서는 동작 모델 설정으로 전달한다. SDO OD나 IO 채널 입력으로 자동 추가하지 않는다.

## 용어와 현재 인터페이스

| 구분 | 예시 | 현재 FMU |
| --- | --- | --- |
| 동작 모델 설정 | 스트로크·직경·질량·센서 감지 폭 | parameter로 노출 |
| 동작 모델 설정 | 정격 유량 | 소스 내부 설정; 외부 노출은 이 RF에서 추가 |
| 명령 입력 | 전진·후진 | Boolean input 2개 |
| 외부 운전 조건 | 공급 게이지압·고정 외력 | parameter로 노출, 초기화 적용 검증 완료 |
| 초기 조건 | 초기 위치 | initial_position으로 노출 |
| 상태·출력 | 위치·속도·챔버 절대압·공압력·끝단 센서·밸브 방향 | output으로 노출 |
| 내부 계산 결과 | 실제 질량 유량 | 현재 외부 input/output 없음 |

현재 XML의 공급압·외력은 tunable로 표시되어 있으나 실행 중 변경 절차와 효과는 미검증이다. 초기 속도·챔버 압력·밸브 방향은 별도의 외부 모델 설정으로 제공하지 않는다.

공급압·외력의 시간 변화 입력화, 실제 유량 출력 노출, 추가 초기 조건 노출은 후속 검토 후보이며 이 RF의 확정 구현 범위에 자동 포함하지 않는다. 이번 확정 요구는 정격 유량의 외부 설정 지원이다.

## 완료 기준

- [ ] 부품별 정격 유량 설정의 이름·단위·정격 조건·기본값·유효 범위를 명세.
- [ ] Modelica 래퍼에서 외부 설정을 해당 부품에 연결하고 외부 parameter가 노출된 FMU를 재Export.
- [ ] Linux FMI 3.0 Co-Simulation 실행, 생성·초기화·계산·종료 검증 및 산출물 해시·재현 절차 기록.
- [ ] 기존 기본값의 왕복·센서·OFF/OFF 방향 유지 회귀.
- [ ] 정격 유량 변경이 해당 유로의 계산에 반영되는지 대조하고 다중 인스턴스 설정 독립성 검증.
- [ ] 잘못된 설정 거부 및 Soft ESC 동작 모델 설정 연결 검증.

## 현재 작업과의 경계

RF-013은 기존 검증 FMU `model_artifacts/SoftESCDoubleActingCylinder-fmi3-web.fmu`를 그대로 사용해 IO 프로파일·어댑터·채널 연결을 진행한다. 이 RF 때문에 FMU를 즉시 교체하거나 IO 작업을 대기시키지 않는다.

상충 명령 판단·인터록·진단은 상위 애플리케이션 책임이다. 어댑터는 두 Boolean 입력을 모두 ON인 경우까지 그대로 전달한다. FMU 호출 실패·자료형 불일치 등 실행/연결 오류 처리는 유지한다.
